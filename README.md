# 🎮 Приключения Малыша — PWA для GitHub Pages

## 📋 Структура проекта

```
adventure-baby-game/
├── index.html              # Основной HTML файл игры
├── manifest.json           # Манифест PWA приложения
├── service-worker.js       # Service Worker для кэширования
├── README.md              # Этот файл
└── .gitignore            # Файл для Git
```

## 🚀 Установка и развёртывание на GitHub Pages

### Шаг 1: Подготовка репозитория

1. Создайте новый репозиторий на GitHub с именем `adventure-baby-game` или `username.github.io`
2. Клонируйте репозиторий на локальный компьютер:
```bash
git clone https://github.com/username/adventure-baby-game.git
cd adventure-baby-game
```

### Шаг 2: Добавление файлов

1. Скопируйте все три файла в корень репозитория:
   - `index.html` — основная игра
   - `manifest.json` — манифест PWA
   - `service-worker.js` — сервис-воркер

2. Убедитесь, что все файлы находятся в корне (не в подпапках)

### Шаг 3: Загрузка на GitHub

```bash
git add .
git commit -m "Add baby adventure game PWA"
git push origin main
```

### Шаг 4: Включение GitHub Pages

1. Перейдите в Settings репозитория
2. Найдите раздел "Pages" в левом меню
3. Установите Source на "main branch" или "main /root"
4. Сохраните изменения
5. Дождитесь развёртывания (обычно 1-2 минуты)

### Шаг 5: Доступ к игре

После развёртывания игра будет доступна по URL:
- `https://username.github.io/adventure-baby-game` (для обычного репозитория)
- `https://username.github.io` (если репозиторий называется `username.github.io`)

## 🔐 Безопасность и HTTPS

GitHub Pages автоматически использует **HTTPS**, что необходимо для работы Service Worker и PWA функций.

Важно! Service Worker требует HTTPS (исключение: localhost).

## 💾 Кэширование и обновления

### Как работает кэширование:

1. **Первое открытие**: загружается с интернета и кэшируется
2. **Последующие открытия**: берётся из кэша (работает офлайн)
3. **Обновления**: при обновлении файлов на GitHub, Service Worker скачает новую версию

### Обновление приложения:

Service Worker автоматически проверяет обновления. Чтобы обновить приложение:

1. Обновите файлы в репозитории
2. Сделайте git commit и git push
3. Дождитесь развёртывания (обычно 1-2 минуты)
4. Переоткройте приложение

## 🛠️ Отладка

### Проверка Service Worker в Chrome DevTools:

1. Откройте DevTools (F12)
2. Перейдите на вкладку "Application"
3. В левом меню выберите "Service Workers"
4. Должна быть активная регистрация

### Проверка кэша:

1. В DevTools > Application
2. Выберите "Cache Storage"
3. Должны быть видны кэшированные файлы

### Проверка манифеста:

1. В DevTools > Application
2. Выберите "Manifest"
3. Должны быть все параметры приложения

## 📞 Поддержка и проблемы

### Service Worker не работает:

1. Убедитесь, что используется HTTPS (GitHub Pages автоматически)
2. Проверьте консоль браузера (DevTools) на ошибки
3. Очистите кэш браузера (Ctrl+Shift+Delete)
4. Перезагрузите страницу (Ctrl+Shift+R)

### Приложение не устанавливается:

1. Проверьте, что браузер поддерживает PWA (современные версии)
2. Убедитесь, что используется HTTPS
3. Проверьте манифест в DevTools
4. Попробуйте другой браузер

### Иконка приложения неправильная:

1. Очистите кэш браузера
2. Переустановите приложение
3. Нажмите на приложение и выберите "Удалить"
4. Переустановите заново

## 📝 Структура файлов

### index.html
- Основной HTML файл
- Содержит все CSS стили (в <style>)
- Содержит весь JavaScript код (в <script>)
- Одного файла достаточно для работы

### manifest.json
- Описание приложения
- Иконки (в формате SVG data-uri)
- Параметры дисплея
- Скриншоты и ярлыки

### service-worker.js
- Регистрация Service Worker
- Кэширование статических ресурсов
- Обработка офлайн-режима
- Обновление приложения

## 🔄 Обновление версии

При обновлении приложения:

1. Обновите `service-worker.js`:
   - Измените `CACHE_NAME` на новую версию (например, 'baby-adventure-v2.1')
2. Обновите `manifest.json`:
   - Измените версию в комментариях (опционально)
3. Загрузите изменения на GitHub

Service Worker автоматически удалит старые кэши и загрузит новые файлы.
